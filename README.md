# WORLDWIRE

Global news intelligence dashboard prototype.

This repository contains the independent WORLDWIRE website. WORLDWIRE MEDIA, the automated YouTube channel, is a separate project.

## Status

Prototype stage. Sample stories are illustrative and must not be treated as current reporting. Live news discovery and editorial verification are not yet production-ready.

## Run locally

Open `index.html` in a modern browser.

## Planned architecture

- Interactive global event map
- News discovery and source links
- Story intelligence panels
- Separate backend for ingestion, research and persistence
- Optional video discovery and authorised partner embeds

Initial development target: free hosting, with no paid services without owner approval.
